Отступы — шкала 8pt

Всё кратно 4/8. Внутри компонента — мелкие шаги (4–16), между блоками — крупные (24–128). Вертикальный ритм секций: desktop clamp(56 → 128), mobile 56–72.

Правило иерархии. Внешний отступ группы всегда больше внутреннего. Не растаскивать связанный текст space-between. Группировка — по близости.

Foundations

Скругления — 4–12px

4 · r-xs
8 · r-sm
12 · r-md
999 · r-pill
Что где:
  • 4 — поля ввода, чипы-фильтры, теги, мелкие кнопки, ячейки таблиц
  • 8 — кнопки, медиа внутри карточки, тосты
  • 12 — карточки, модалки, карта, крупные медиа-блоки
  • 999 — только status-pip юнита, аватар, точка-маркер. Кнопки НЕ пилюли (отличие от мастер-бренда).

Foundations

Сетка · тени · движение

Сетка

  • 12 колонок
  • Контейнер: 1200 (рамка) / 1120 (контент)
  • Гаттер 24 / gap 24 · моб. 16
  • Брейкпоинты: 480 · 768 · 1024 · 1280
  • Full-bleed: hero, карта, медиа-полосы

Тени

  • Карточки по умолчанию — без тени, только 1.5px линия
  • sh-1 — тонкая, для приподнятых списков
  • sh-2 — только модалки / выпадашки / sticky-меню
  • Hover карточки — усиление линии, без «взлёта»

Движение

  • Ховер/состояния — 160ms ease
  • Появление секций — 240ms ease-out, сдвиг 8–12px
  • Без тяжёлого параллакса (это тёмный era.estate; мы светлые)
  • prefers-reduced-motion — выключаем reveal

Components

Паттерн секции

  • padding-block: clamp(56px, 8vw, 128px)
  • Заголовок: overline (accent) → H2 (ink, 500) → опц. интро Body-L (макс. 60ch)
  • Промо-блоки (hero, локация, «почему мы») — просторно: крупная типографика, воздух
  • Функциональные (каталог, доходность, юнит-микс) — плотно: сетка, таблицы, данные на виду
  • Sticky sub-nav (переключатель U1/U2/U3, чипы каталога): высота 56, --surface, нижняя линия 1px, опц. backdrop-blur

Handoff

Токены — :root для hi-fi

Источник правды. Прототип и будущий макет тянут отсюда — правка одного значения меняет весь визуал.

:root{
  /* COLOUR */
  --bg:#F5F5F6; --surface:#FFFFFF; --surface-2:#ECECEE;
  --ink:#1A1A1D; --ink-2:#3A3A3D; --ink-3:#8A8A90;
  --line:#E2E2E5; --line-strong:#C9C9CE;
  --accent:#1B3BEE; --accent-ink:#FFFFFF; --accent-tint:#1B3BEE14;
  --ok:#1E9E63; --warn:#C98A12; --gone:#8A8A90;

  /* SPACING · 8pt */
  --s-1:4px; --s-2:8px; --s-3:12px; --s-4:16px; --s-5:24px;
  --s-6:32px; --s-7:48px; --s-8:64px; --s-9:96px; --s-10:128px;

  /* RADIUS · 4–12 */
  --r-xs:4px; --r-sm:8px; --r-md:12px; --r-pill:999px;

  /* TYPE */
  --font:"Inter","Helvetica Neue",Helvetica,Arial,sans-serif;
  --mono:"IBM Plex Mono",ui-monospace,SFMono-Regular,Menlo,monospace;
  --fw-reg:400; --fw-med:500; --fw-semi:600;

  /* ELEVATION */
  --sh-1:0 1px 2px rgba(0,0,0,.04);
  --sh-2:0 8px 28px rgba(18,18,28,.10);

  /* LAYOUT */
  --container:1200px; --content:1120px; --gutter:24px; --col-gap:24px;

  /* MOTION */
  --t-fast:160ms ease; --t-rev:240ms cubic-bezier(.2,.6,.2,1);
}

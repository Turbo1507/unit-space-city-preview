A. Прямые конкуренты — Бали / Nuanu

Тот же рынок, покупатель и контекст локации.

Nuanu Creative City — главная

nuanu.com
Приёмы
  • Полноэкранное видео, горизонтальный скролл-парад проектов
  • Нарратив экосистемы: миссия, обязательства (70% зелени, 15 000 деревьев) в табах
  • Эмоция «место, где каждый угол рассказывает историю»
Берём: локация-первой (аэро/видео Nuanu), storytelling вместо «о проекте», табы обязательств.

Nuanu — страница Invest

nuanu.com/invest
Приёмы
  • Сегмент-переключатель: Real Estate / Commercial / Business / Living
  • Полоса цифр: 13% ROI · 13 проектов · +50% за 5 лет
  • Фильтруемые карточки проектов — атом: ROI-диапазон + min-цена IDR + срок leasehold + «Learn more»
  • Блок «Advantages»: Seismic Design, Flood Management — снимают страхи
  • Лид-форма с дропдауном «Segment of interest»; блок Personal Concierge (WhatsApp / IG / email / Book a call)
Берём: сегмент-переключатель под U1/U2/U3; карточка проекта = ROI+цена+срок; блок «снимаем страхи»; единый концьерж-блок.

Nuanu — внутренняя страница проекта

nuanu.com/invest/the-sense

  • 3 коротких абзаца ценности + 4 подробные плитки «Advantages»
  • Повтор концьерж-блока внизу
Берём: лаконичный шаблон страницы проекта; явный юнит-микс числом; повтор CTA/контакта.

B. Мировые эталоны — UX/UI

Не рынок Бали — берём приёмы подачи, структуру, интерактив.

Aston Martin Residences (Майами)

astonmartinresidences.com
Приёмы
  • Иммерсивный одностраничник; навигация = главы (Heritage / Residence / Amenities / Location / Floorplans / Gallery / Contact)
  • Полноэкранное видео; крупные редакционные заголовки-стейтменты («PASSION FOR PERFECTION») + «EXPLORE»
  • Виртуальная арт-галерея / тур
  • Планировки — за формой-воротами; цен нет; единственное действие «Schedule a Meeting»
Берём: структура-главы; заголовки-стейтменты вместо «О проекте»; brand-story (архитектор, почему); планировки как gated-актив (частично).

  • Планировки сгруппированы в коллекции (River / Panoramic / Sky / Penthouses)
  • Доступ через «EXPLORE» → регистрация / запрос
Берём: планировки как коллекции по «линейке»/этажу; мягкий гейт (можно смотреть, скачать PDF — за контакт).

The Modern House (Лондон) — главная

themodernhouse.com
Приёмы
  • Редакционное, «журнальное»: гигантский serif, воздух, крупная фотография

Берём: «журнальность» вместо «риелторщины»; тип владения + срок как явный атрибут карточки; пул-цитаты; подписка на алерты.

Синтез — черновик структуры прототипа U1 · U2 · U3

  1. Hero — видео/аэро Nuanu, ценовой якорь «от $X», 1 CTA (Book a call / WhatsApp)
  2. Полоса цифр — ROI, срок leasehold, кол-во юнитов, срок сдачи
  3. Переключатель U1 / U2 / U3 — дальше контент под выбранный проект
  4. Блок проекта — редакционное описание + юнит-микс + галерея (наши фото-паки) + планировки-коллекции
  5. Каталог юнитов — фильтры (статус, спальни, площадь, этаж, цена, фаза/сдача) + живой счётчик + карточка с планировкой-миниатюрой + бейдж (Доступно / Мало / Продано)
  6. Доходность — таблица по сценарию + ROI-калькулятор + графики рынка Бали
  7. Локация — интерактивная карта Nuanu + инфраструктура + время до точек
  8. Доверие — прогресс стройки (фото по датам), документы (leasehold, разрешения), застройщик, отзывы + цитаты прессы
  9. «Снимаем страхи» — сейсмика, паводок, покупка иностранцем, PT PMA, процесс по шагам
  10. FAQ-аккордеон — SEO + возражения
  11. Финальный CTA + концьерж-блок (WhatsApp / IG / email / Book a call) + PDF-гайд за контакт

Тон: редакционный (The Modern House / Aston Martin), не риелторский. 2-цветная палитра + акцент, воздух, крупная типографика, реальная фотография. Язык: RU + EN, переключатель валюты $/IDR.
